# Simple Expense Tracker

A small Python command-line application for recording expenses, viewing saved entries, and calculating total spending.

## Features

- Add an expense with a date, category, description, and amount
- List previously saved expenses
- Calculate total spending
- Store entries locally in a CSV file
- Uses only Python's standard library

## Requirements

- Python 3.10+
- No external packages

## Run

From this folder, run:

```bash
python expense_tracker.py
```

The application creates `expenses.csv` in the same folder when you add your first expense.

## What this project demonstrates

- Functions and loops
- User input and validation
- Working with dates and decimal amounts
- CSV file reading and writing
- Basic error handling
- Separating program logic into functions

## Possible improvements
